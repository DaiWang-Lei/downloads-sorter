下载整理 · Windows 版
====================

自动把「下载」文件夹里新下载的文件，按规则移到对应的分类文件夹：
发票 → 30_财务\发票，安装包 → 90_安装包，图片 → 60_图片……
规则判断不了的放进 00_收件箱，留给你每周手动整理一次。只移动，不删除任何文件。


一、安装
1. 把「下载整理.exe」放到一个固定的位置，例如 D:\Tools\下载整理\
   （不要直接在压缩包里双击运行，也不要放在「下载」文件夹里）
2. 双击运行。第一次运行时如果出现「Windows 已保护你的电脑」：
   点「更多信息」→「仍要运行」。这是因为程序没有购买数字签名，不是病毒。
3. 图标会出现在任务栏右下角（没看到的话点 ^ 展开，可以把它拖到任务栏上常驻）。
4. 点击图标 → 勾选「开机自动启动」。


二、菜单说明
- 自动整理：总开关。新文件下载完成并静止 2 分钟后自动归类
- 立即整理：只等 10 秒，马上处理
- 打开收件箱：查看规则判断不了、等你手动整理的文件
- 最近整理：最近移动过的文件，点一下在资源管理器里定位
- 编辑规则…：在浏览器里打开规则编辑页，改完点「保存」立即生效
- 打开日志：查看每次移动的记录


三、默认规则（从上到下，第一条命中的生效）
- 文件名含「发票 / invoice」，或从百望云、诺诺等发票平台下载 → 30_财务\发票
- 文件名含「交易明细 / 账单 / 流水 / 对账单」               → 30_财务\账单流水
- 文件名含「简历 / resume」                               → 10_个人档案\简历
- .exe .msi .msix 等安装程序，名字像安装包的 zip/7z/rar     → 90_安装包
- .epub .mobi .azw3                                       → 40_学习\电子书
- 图片（jpg png heic webp 等）                             → 60_图片
- .yml .json .ini .ps1 .bat .py .sql 等                   → 50_代码与配置
- 其他                                                    → 00_收件箱

不会动的：还没下载完的文件（.crdownload .part 迅雷 .xltd 等）、
正在被其他程序打开的文件、隐藏文件、Office 临时文件（~$ 开头）、
以及已有的 00_～99_ 分类文件夹。文件夹要 1 小时没有变动才会移进收件箱。


四、文件位置
- 规则：%APPDATA%\下载整理\rules.json（与 Mac 版格式通用，可以互相拷贝）
- 日志：%APPDATA%\下载整理\下载整理.log


五、卸载
1. 点击图标 → 取消「开机自动启动」→ 退出
2. 删除「下载整理.exe」和 %APPDATA%\下载整理 文件夹
